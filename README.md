# Market2Farm 🌱

AI-Powered Agricultural Marketplace connecting farmers directly to buyers.

## Features
- 🛒 Marketplace with admin-approved products
- 🤖 AI Crop Disease Detection
- 🌤️ Climate Intelligence
- 💳 Secure Payments (M-Pesa, Airtel Money, Bank Transfer, PayPal, Stripe, Binance)
- 👑 Admin Dashboard with full control
- 💬 AI Chatbot Assistant
- 🌍 Multi-currency Support (KSH/USD)
- 🔐 2FA Authentication
- 📱 Responsive Design

## Tech Stack
- **Backend:** Flask, SQLAlchemy
- **Database:** PostgreSQL / SQLite
- **AI:** OpenAI API
- **Payments:** Stripe, M-Pesa
- **Storage:** Cloudinary
- **Deployment:** Render
